How to draw a character so that it becomes a Sinua character that animates and wears [cosmetics](/docs/catalog/cosmetics). The convention uses only **layer names and plain shapes**, so it survives Figma, Illustrator, Inkscape and AI drawing tools. The [Studio](/docs/studio) imports a file drawn this way; by hand, the same names map to a recipe's `role`, `slots` and eyes (see the [recipe reference](/docs/reference/character-recipe) and [Make your own character](/docs/catalog/own-character)).
