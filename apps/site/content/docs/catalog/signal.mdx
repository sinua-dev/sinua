## When to use which pattern

| Pattern | `pattern` | When to use it |
|---|---|---|
| [Bars](#signaling) | `signaling` | Live level: bars that follow the audio. |
| [Waveform](#waveform) | `waveform` | Live voice: layered waveform lines. |
| [Scrolling](#scrolling) | `scrolling` | Voice over time: a scrolling history of levels. |
| [Meter](#metering) | `metering` | A precise meter: an LED matrix with peaks. |

## Props

Every prop, per pattern. **Values** are your app's data; everything else is style. Defaults can differ per size (20 · 32 · 64).
