# Upstream sources

Everything this project pulled from outside its own repo, with exact paths — one consolidated list, since the individual docs each reference only the part relevant to them. Every path below is inside one repo: **[`Jakubantalik/Libraries.dev`](https://github.com/Jakubantalik/Libraries.dev)** (Jakub Antalik).

## Vendored code (MIT-licensed, copied/ported)

The library packages in that repo (`packages/*`) carry a root `LICENSE` file — MIT, confirmed by reading it directly (both the repo-root `LICENSE` and `packages/thinking-orbs/LICENSE` were fetched and checked; identical text).

| Upstream path | Landed here as |
|---|---|
| `packages/thinking-orbs/src/engine/*.ts` | `crates/core_engine/src/orbs/{core,profiles,presets}.rs` + the 9 ported `modes/*.rs` (orbits, globe, rubik, wave, web, braid, ribbon, morph; `breathing` reuses ribbon) — line-by-line port, see [`engine.md`](engine.md#provenance) |
| `packages/thinking-orbs/spec/orbs-spec.json` | `spec/orbs-spec.json` — vendored verbatim, never hand-edited |
| `packages/thinking-orbs/spec/orbs-golden.json` | `spec/orbs-golden.json` — vendored verbatim, the frozen test vectors everything is proven against. Captured upstream at `9d735d1` (2026-08-16, the only commit that ever touched it), sizes 64 and 20 |
| `packages/thinking-orbs/src/{engine/*,presets}.ts` @ `2015f0b`, run unmodified at size 32 | `spec/orbs-golden-32.json` — the same oracle at the size the vendored file lacks, generated by `scripts/oracle/extract-orbs-golden.ts`. Valid because the same commit and harness reproduce `orbs-golden.json` byte for byte ([`scripts/oracle/README.md`](../scripts/oracle/README.md)) |
| `packages/thinking-orbs/LICENSE` | `third_party/thinking-orbs/LICENSE` — attribution kept alongside the code it covers; also shipped as `THIRD_PARTY_LICENSES` in `packages/{core,ios,android,react-native}` and the three Studio apps (the ones that contain the compiled engine), and pointed to from the root `LICENSE`/`NOTICE` |

**This is the only code actually copied or transcribed.** Nothing else below was copied — each is either a read-only architecture reference or a design-decision input.
