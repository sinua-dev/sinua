A colour ramp by position across the frame. In an FX Spec: `/gradient`. Off until `gradient.strength` is above 0.

| Prop | FX Spec | Type | Range | Default | Description |
|---|---|---|---|---|---|

| `gradient.hue3` | `/gradient/hue3` | number | -720–1080 deg |  | Optional third stop's hue; absent = a two-stop ramp. |
| `gradient.hue` | `/gradient/hue` | number | 0–360 deg | 200 | Hue at the start of the ramp. |

| `gradient.saturation` | `/gradient/saturation` | number | 0–1 fraction | 0.8 | Saturation the ramp blends toward. |
