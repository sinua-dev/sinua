## When to use which pattern

| Pattern | `pattern` | When to use it |
|---|---|---|
| [Working](#working) | `working` | Busy, processing: particles on orbits. The default "thinking" look. |
| [Searching](#searching) | `searching` | Looking something up: a globe with a scanning band. |
| [Solving](#solving) | `solving` | Working through a hard problem: a sphere turning layer by layer. |
| [Listening](#listening) | `listening` | Taking input: a calm wave surface. Pairs well with the voice level. |
| [Connecting](#connecting) | `connecting` | Establishing a link: a network with pulses travelling along it. |
| [Weaving](#weaving) | `weaving` | Combining things: braided strands. |
| [Composing](#composing) | `composing` | Writing or drafting: a turning ribbon. |
| [Breathing](#breathing) | `breathing` | Idle but present: a slow ribbon. A good base design. |
| [Shaping](#shaping) | `shaping` | Transforming: dots morphing between icon outlines. |
| [Glowing](#glowing) | `glowing` | Ambient, decorative: an aurora of colour on a sphere. |
| [Drifting](#drifting) | `drifting` | Ambient, calm: a flowing network that sheds particles. |
| [Speaking](#speaking) | `speaking` | Output with sound: a spectrum that follows the voice. |
| [Confirming](#confirming) | `confirming` | Done, acknowledged: a sonar ping. |
| [Initializing](#initializing) | `initializing` | Starting up: a warp field. |
| [Calibrating](#calibrating) | `calibrating` | Settling, tuning: dots forming standing-wave patterns. |
| [Progressing](#progressing) | `progressing` | Progress on a round object: an eclipse that advances with `progress`. |
| [Silhouette](#silhouette) | `silhouette` | A voice agent with a presence: a head and shoulders of glowing dots. See [below](#a-head-and-shoulders). |
| [Muted](#muted) | `muted` | Muted or paused: a dimmed, slowly breathing sphere with an optional warning tint. |

## A head and shoulders

`silhouette` draws a front-facing head and shoulders from evenly spread dots that live with the voice. One shape stays on screen; the voice states only change how it moves: it breathes at rest, draws in while you talk, flickers along the eye line while thinking, and sends waves out from the mouth while speaking.

- **Which head:** `silhouette` in an FX Spec is `"human"` (the default) or `"helmet"`, or your own outline: `{ "path": "M… Z", "eyes": [left x, right x, y], "mouth": [x, y] }` in a 200 × 200 box. Start and end the path below the shoulders; the bottom stays open and fades.
- **Looks:** `hologram` (a bright rim and a thin band sliding now and then), `scanlines`, `wire` (links between neighbours), `turnYaw` (the head turns, the shoulders stay), `rim`, `dotSize`, `saturation` and `hue`.
- **Dots:** about 1,500 at 64 px, 380 at 32 px, the outline alone at 20 px. Under low power it draws 800.
- **Cost:** medium. Glow on every dot makes it heavy, so the voice states leave the dot glow off.

```json
{ "fxSpec": "1.13", "object": "orb", "pattern": "silhouette", "silhouette": "helmet",
  "params": { "hologram": 1, "scanlines": 0.6, "saturation": 0.5, "hue": 190 } }
```

Every prop, per pattern. **Values** are your app's data; everything else is style. Defaults can differ per size (20 · 32 · 64).
