## When to use which pattern

| Pattern | `pattern` | When to use it |
|---|---|---|
| [Notifying](#notifying) | `notifying` | Something happened: a ping ripple (can play once). |
| [Reconnecting](#reconnecting) | `reconnecting` | Connection quality: a pulse with lit segments. |
| [Locating](#locating) | `locating` | Position with uncertainty: a halo that shrinks as accuracy rises. |
| [Scanning](#scanning) | `scanning` | Scanning an area: a radar sweep with blips. |
| [Broadcasting](#broadcasting) | `broadcasting` | Sending out: waves from a centre, driven by `level`. |

## Props

Every prop, per pattern. **Values** are your app's data; everything else is style. Defaults can differ per size (20 · 32 · 64).
