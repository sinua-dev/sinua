A character can **wear things**: a hat, glasses, a scarf, a badge. A cosmetic is data in the FX Spec file, drawn by the engine, so it looks the same on the Web, iOS, Android and React Native, moves with the character, and needs no Sinua release. The engine ships none of its own; a file carries each one it uses, or loads a ready-made pack.
