Import the component for your object and render it. It draws into a canvas, sizes itself to its box (DPR capped at 2), pauses when off screen or in a hidden tab, and never runs the engine during server rendering.

<include lang="tsx" meta='title="react.tsx"'>../../../snippets/web/react.tsx</include>

React has both: `SinuaView` for a pattern or a spec, and the typed components — `SinuaOrb`, `SinuaRing`, `SinuaSignal`, `SinuaCore`, `SinuaBeacon` — from `@sinua/web/components`, which take each pattern's own props by name.

Typed components take the same props on every platform: `pattern` (or `spec`), [values](/docs/connect/values), [style](/docs/look/color-and-theme), `state`, `voice`, `theme`, `paused`, `reducedMotion`, `maxFps`, `lowPower` and an accessibility label. The [catalog](/docs/catalog) lists every prop per pattern.

The visual's background is transparent; give the component a size with CSS.
