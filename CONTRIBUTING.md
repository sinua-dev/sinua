# Contributing

Sinua is developed by its maintainers. **We are not accepting outside code contributions
at the moment**: pull requests from outside the team are closed without review. This
keeps every change under one review and release process while the API is in beta.

What helps, and is welcome:

- **Bug reports** as GitHub issues: the platform (Web, iOS, Android, React Native), the
  package and version (`0.1.0-beta.N`), the pattern or FX Spec file, and what you saw.
- **Security problems** go through [SECURITY.md](SECURITY.md), not public issues.

The code is Apache-2.0: you are free to fork it under that licence.
