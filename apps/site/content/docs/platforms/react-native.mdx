title: React Native
description: The Sinua components for React Native (iOS and Android).
---

`@sinua/react-native` gives you the same typed components in React Native. They're native views (Fabric) over the iOS and Android views, so animation runs natively, not over the bridge.

<include lang="tsx" meta='title="react-native.tsx"'>../../../snippets/platforms/react-native.tsx</include>

The typed components take the same props on iOS, Android and React Native: `pattern` (or `spec`), [values](/docs/connect/values), [style](/docs/look/color-and-theme), `state`, `voice`, `theme`, `paused`, `reducedMotion`, `maxFps`, `lowPower` and an accessibility label. The [catalog](/docs/catalog) lists every prop per pattern.
