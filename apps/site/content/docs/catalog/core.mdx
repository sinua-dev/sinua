## When to use which pattern

| Pattern | `pattern` | When to use it |
|---|---|---|
| [Generating](#generating) | `generating` | Content is being generated: a shimmering skeleton line. |
| [Typing](#typing) | `typing` | Someone is typing: three bouncing dots. |
