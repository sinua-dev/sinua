title: Current limits
description: What Sinua doesn't do today, and what to do instead.
---

Plain statements of where the edges are right now. Each one says what to do in the meantime.

## It's a beta

The packages are published as `0.1.0-beta.N`: npm's `beta` tag, Maven Central and SwiftPM. The API can still change between betas; the [changelog](/docs/resources/changelog) says what did. On npm, install with `@beta`: the untagged name still resolves to the first beta.

## React Native isn't on npm yet

`@sinua/react-native` is built from the repository for now — [Installation](/docs/getting-started/installation) has the steps. The web, iOS and Android packages are published.

## The voice adapters are beta

The LiveKit, OpenAI Realtime, Gemini Live and ElevenLabs sources are tested against simulated sessions, not yet against each live service. If one misbehaves with your agent, an issue with the vendor and platform helps most.

## An FX Spec holds one object

One file describes one object in its states. For a screen with an orb *and* a progress ring, write a file each and mount two views.

## Colour is hex, HSL or a named CSS colour

There's no OKLCH or wide-gamut input; a colour you give is converted with the same maths on every platform. See [Colour & theme](/docs/look/color-and-theme).

## Counts and choices don't flow between states

State changes animate. When a change keeps the pattern (every voice state, most FX Spec states), the parameters and the speed interpolate, so one shape flows into the next. The orb lattice trio (glowing, calibrating, progressing) morphs point by point. Any other pattern change cross-fades. The default is 0.6 s easeInOut, set per state pair in the file's [`transitions`](/docs/reference/fx-spec#transitions). Counts and choices (a particle count, a style) can't interpolate: they swap in a brief dissolve mid-way.

## The cost badge doesn't measure compute

[`estimateCost`](/docs/performance) counts elements, how much of the canvas they cover and how much blur they need. A pattern that computes a lot while drawing little — liquid is the clear case — ranks lower than it should. For anything performance-critical, measure on the device rather than trusting the badge.

## Where to follow along

The [repository](https://github.com/sinua-dev/sinua) is the source of truth for what exists today: the engine, the specs, the tests and the docs you're reading are all in it. Bug reports go to its issues.
